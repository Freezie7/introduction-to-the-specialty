# KIE AI Image Generator (Frontend + Backend)

Минималистичное веб-приложение для генерации изображений по текстовому описанию (промпту) с использованием нейросетей.

## 💡 Идея проекта и функциональность

Сервис позволяет пользователям визуализировать свои идеи с помощью ИИ в простом и понятном интерфейсе.

**Основные возможности:**
* **Генерация по промпту**: Пользователь вводит текстовое описание, и система создает изображение.
* **Асинхронная работа**: Реализован механизм поллинга для получения результата.
* **Предпросмотр**: Отображение сгенерированного изображения прямо на странице.
* **Безопасность**: Все запросы к внешним API проходят через бэкенд — API-ключ не утекает на клиент.

## 🏗 Архитектура

1. **Frontend**: HTML5, CSS3, Vanilla JavaScript
2. **Backend**: Node.js, Express — прокси-сервер между фронтендом и KIE AI API
3. **Внешняя интеграция**: KIE AI API (модель `nano-banana-2`)

## 🛠 Запуск локально

```bash
cd backend
npm install
cp .env.example .env
# Указать KIE_API_KEY в .env
npm start
```

Фронтенд — открыть `frontend/index.html` в браузере или через `npx serve ./frontend`.

## 🐳 Запуск через Docker

```bash
docker build -t kie-backend ./backend
docker run -p 3100:3100 -e KIE_API_KEY=твой_ключ kie-backend
```

## ✅ Тесты

```bash
cd backend
npm test
```

4 unit-теста для функции `extractImageUrl` — парсинг ответов от KIE AI API.

## 🔌 API эндпоинты

- `POST /api/generate-image` — создание задачи на генерацию, принимает `{ prompt }`
- `GET /api/image-status?taskId=...` — получение статуса задачи
- `GET /health` — проверка работоспособности сервера
