# KIE AI Image Generator (Frontend + Backend)

Минималистичное веб-приложение для генерации изображений по текстовому описанию (промпту) с использованием нейросетей. Проект разработан как учебное задание для освоения полного цикла создания веб-приложения: от идеи до реализации.

## 💡 Идея проекта и функциональность
Сервис позволяет пользователям визуализировать свои идеи с помощью ИИ в простом и понятном интерфейсе.

**Основные возможности:**
* **Генерация по промпту**: Пользователь вводит текстовое описание, и система создает изображение.
* **Асинхронная работа**: Поскольку генерация занимает время, реализован механизм опроса (поллинга) сервера для получения результата.
* **Предпросмотр**: Отображение сгенерированного изображения прямо на странице с возможностью скачать оригинал.
* **Безопасность**: Все запросы к внешним API проходят через собственный бэкенд, что предотвращает утечку API-ключей.

## 🏗 Архитектура
Приложение построено по классической схеме разделения ответственности:

1.  **Frontend (Клиент)**:
    * Стек: HTML5, CSS3, Vanilla JavaScript.
    * Логика: Обработка ввода, управление состояниями интерфейса (загрузка/результат) и взаимодействие с API через `fetch`.
2.  **Backend (Сервер)**:
    * Стек: Node.js, Express.
    * Роль: Прокси-сервер. Он принимает запросы от фронтенда, добавляет заголовки авторизации и перенаправляет их к API KIE AI. Это позволяет скрыть конфиденциальные данные от конечного пользователя.
3.  **Внешняя интеграция**:
    * Использование API KIE AI (модель `nano-banana-2`) для обработки нейросетевых задач.

## 🛠 Инструкция по запуску

### 1. Настройка Backend-сервера
Перейдите в директорию сервера, установите зависимости и настройте переменные окружения:

```bash
cd backend
npm install
cp .env.example .env
В файле .env необходимо указать ваш персональный ключ:
KIE_API_KEY=ваш_секретный_ключ
```
Запуск сервера:

```bash
npm run start
```
Бэкенд будет доступен по адресу: http://localhost:3100

2. Запуск Frontend-клиента
Фронтенд состоит из статических файлов. Вы можете просто открыть index.html в браузере или использовать любой локальный сервер (например, расширение Live Server в VS Code или пакет serve):

```bash
cd frontend
# Если установлен serve:
npx serve .
```
🔌 Описание внутренних API-эндпоинтов
POST /api/generate-image — создание новой задачи на генерацию. Принимает JSON с полем prompt.

GET /api/image-status?taskId=... — получение текущего статуса задачи и ссылки на готовый файл.
